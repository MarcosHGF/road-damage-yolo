# predict_sample

A handful of RDD2022 **test** images (one per country) used as inputs for the
demo gallery (`reports/demo_gallery.html`) and the qualitative-predictions page
of the training report.

**Source & license.** These images are from the RDD2022 dataset
(CRDDC'2022, Arya et al., 2022) and are licensed **CC BY-SA 4.0**. See
[`../../NOTICE.md`](../../NOTICE.md) for attribution and the full citation.
